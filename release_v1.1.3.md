## A clean restart after updates

PoE Price Checker now stops its global keyboard and mouse listener before Windows shuts down the app. This fixes a crash that could occur while quitting or restarting to install an update.

Open **Settings → Application** and choose **Check for updates**. When the download is ready, choose **Restart to update**. The installed and portable editions of v1.1.2 can both update in place. Installed v1.1.1 users can update with **Automatic updates** on. Portable users on v1.1.1 or earlier can move to the [new portable edition](https://github.com/CyanBalloon/poe-price-checker/releases/download/v1.1.3/poe-price-checker-1.1.3.exe) once, then update inside the app.

This release includes the restored PoE2 pseudo-stat filters and Windows client-log fix from [v1.1.2](https://github.com/CyanBalloon/poe-price-checker/releases/tag/v1.1.2).
