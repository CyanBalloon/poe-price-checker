## Open trade

Click **Open trade** on a listing to open its search in your default browser. This fixes clicks that did nothing when the trade API returned structured modifiers, including on PoE1 maps. On Windows, long searches now use a short trade link. If the trade service cannot create that link, the button opens the current results.

## Mageblood icon

Look for the Mageblood belt on the Windows taskbar and in the system tray. The same in-game artwork now appears in both game modes, the installer, the portable edition, and the project website.

To update an existing installation or portable copy, open **Settings → Application → Check for updates**.
