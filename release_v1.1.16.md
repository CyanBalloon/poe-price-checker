## Price Check

- **View all mods** is now the first tab under Filters in PoE1 and PoE2. Selected modifiers still appear first in the list.
- The filter panel shows the item's rolls alongside the values used in your trade search.
- PoE1 recognises more clipboard modifiers and handles Eldritch influence markers as item influence.
- Chronicle of Atzoatl searches use open-room filters for the selected rooms.
- Item previews show influence indicators together. The public build uses the checker's own colour highlights.

Update from **Settings → Application → Check for updates**. Both installed and portable Windows builds support in-app updates.
