## Price checks

- The Windows price-check hotkey brings the checker to the foreground after the item is copied, even when the window is minimized or hidden.
- Price checks release the simulated copy modifiers immediately to prevent the brief advanced-tooltip flash while keeping detailed modifier data.
- PoE1 map searches select rare-only modifiers by default, including when the game uses localized modifier descriptions. Viscera searches keep their implicit modifiers selected.

## Settings and trade

- Settings includes a GitHub link under **Application**.
- Dropdowns share a consistent style across Settings and trade, and pressing Escape dismisses an open listing dropdown first.

Use **Settings → Application → Check for updates** in either Windows edition to install the update.
